# Global Superstore Return Analysis Dashboard

## Project Overview
An interactive Power BI dashboard designed to analyze product returns in the Global Superstore dataset. It provides insights into return trends, product categories, customer segments, and geographic distribution.

## Key Features
- KPI cards for orders, returns, and customers
- Monthly return trend analysis
- Returns by product category and sub-category
- Customer segment and regional analysis
- Geographic visualization of returns
- Interactive slicers for year, category, region, and segment

## Tools Used
- Microsoft Power BI
- DAX
- Excel

## Objective
To identify return patterns across products, customers, and regions and support data-driven business decisions.

## Dataset
Global Superstore dataset containing order, customer, product, geographic, and return information.
